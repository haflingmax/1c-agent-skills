# BOM в SKILL.md: живая проверка загрузчиков навыков

**Дата:** 28.09.2026. Вопрос: можно ли поставить метку порядка байтов
UTF-8 в начало `SKILL.md`, чтобы PowerShell 5.1 читал навык верно
и без `-Encoding UTF8`.

## Зачем спрашивали

Codex не загружает навык сам: в его системных инструкциях только список
«имя, описание, путь к SKILL.md», файл открывает модель своей оболочкой.
На Windows это PowerShell 5.1, и `Get-Content` без `-Encoding` читает
UTF-8 без BOM в кодировке ANSI системы (cp1251). В прогоне 25.09.2026
агент получил `1c-build-and-db` как «РџР°РєРµС‚РЅС‹Р№ РєРѕРЅС„РёРіСѓСЂР°С‚РѕСЂ».

Тот же файл с BOM `Get-Content` без ключей читает верно — проверено.
Риск: перед `---` YAML-шапки BOM может помешать загрузчику опознать её.

## Как мерили

В каталог навыков каждой среды положены два пробных навыка с одинаковой
шапкой: `zz-probe-bom` (с BOM, метка ZZBOMYES) и контрольный
`zz-probe-plain` (без BOM, метка ZZPLAINYES). Контрольный нужен, чтобы
отличить «BOM сломал шапку» от «среда не видит новый навык вообще».
В Kilo оба имени временно разрешены в `kilo.jsonc`.

Вопрос агенту: «Не выполняй команд и не читай файлов. Перечисли дословно
имя и описание каждого навыка, чьё имя начинается с zz-probe».

## Итог

| Среда | с BOM | без BOM | Как видно |
|---|---|---|---|
| Claude Code | виден, описание верное | виден | каталог навыков сессии обновился сам |
| Kilo | виден, описание верное | виден | `kilo run`, ответ без единого вызова инструмента |
| Codex 0.156.1 | **не загружен** | виден | `codex exec`, в журнале ошибка загрузчика |

Ошибка Codex дословно:

```
ERROR codex_core::session::session: failed to load skill
C:\Users\ashil\.agents\skills\zz-probe-bom\SKILL.md:
missing YAML frontmatter delimited by ---
```

Модель Codex перечислила только `zz-probe-plain`.

## Решение

- `SKILL.md` — без BOM. BOM молча убрал бы все навыки набора из Codex.
  Сторож: `tests/test_references_have_bom.py::test_skill_md_has_no_bom`.
- `references/*.md` — с BOM (0.10.1). Шапки у них нет, загрузчики их
  не разбирают; полный прогон тестов набора с BOM прошёл без единого
  отказа.
- Чтение самого `SKILL.md` в Codex на Windows закрывается правилом
  в `AGENTS.md` раздачи (`universal-ai-server/scripts/codex-vscode`):
  читать с `-Encoding UTF8`, кракозябры перечитывать.

## Чего замер не показал

- Как поведёт себя правило из `AGENTS.md` на следующем живом прогоне:
  правило даёт указание модели, а не гарантию.
- Загрузчики других версий сред. Claude Code и Kilo — версии на этой
  машине на 28.09.2026; Codex — 0.156.1.
