# План реализации: логика планирования

> **Исполнителю:** ОБЯЗАТЕЛЬНЫЙ ПОДНАВЫК — `superpowers:subagent-driven-development`
> либо `superpowers:executing-plans`. Шаги помечены чекбоксами `- [ ]`.

**Цель:** заставить навык планировать по признаку, а не по чек-листу, и убрать
блокировки законной работы — так, чтобы обе крайности проверялись запуском на каждом шаге.

**Подход:** сначала чинится проверяльщик, потому что он единственный даёт
детерминированный сигнал; затем тексты переводятся с перечней на признаки; на каждой
задаче — пара прогонов-антиподов на живой платформе.

**Спека:** [docs/specs/2026-08-22-planning-logic-design.md](../specs/2026-08-22-planning-logic-design.md)

**Общий план проекта:** [docs/plan.md](../plan.md). Этот план подчинён ему, относится
к этапам ЯДРО-5 и ЯДРО-6 и закрывает дефекты Д-13…Д-23.

## Global Constraints

- Платформа для прогонов: `C:/Program Files/1cv8/8.3.27.2325/bin/1cv8.exe`.
- База для прогонов: `D:/1C/base/trade`, файловая, **одноразовая** — портить разрешено.
- `1cv8.exe` возвращает управление немедленно: запускать только через
  `Start-Process -Wait`, иначе тихий отказ неотличим от успеха.
- Успех операции 1С определяется **по результату**, а не по `DumpResult` и не по `/Out`:
  оба соврали на выдуманном ключе.
- Технологический журнал (`logcfg.xml`) источником не служит и его включение
  предлагать запрещено — ограничение владельца.
- `ibcmd.exe` на машине отсутствует: ветка `ibcmd` непроверяема, помечать как требующую сервера.
- Скрипт блокирует только противоречащее документированному составу приложения 7;
  всё зависящее от замысла — `[внимание]` с кодом 0.
- Никаких таблиц «значение → вердикт» в навыках. Только контрастные пары.
- Каждое утверждение о необратимости несёт ссылку на источник.
- Проверка навыков обязана проходить: `python tools/check-skills.py` возвращает 0.
- Кодировка вывода в прогонах: `PYTHONIOENCODING=utf-8`, иначе консоль ломает кириллицу.

- [ ] **Шаг 3: Заменить разрешение имени ключа**

В `check-1c-cli.py` заменить блок слитных ключей на точную функцию. Слитным считается
только ключ, у которого в каталоге аргумент начинается с `<`, то есть значение
приклеивается по документации:

```python
def known_key(name, keys):
    """Возвращает каноническое имя ключа или None.

    Регистр не важен: платформа регистронезависима, проверено запуском
    (/dumpcfg отработал и создал файл). Слитное значение допускается только
    у ключей, документированных как /Имя<значение> — например /L<код языка>.
    Для остальных совпадение по началу имени запрещено: иначе выдуманный
    /DumpCfgToFile молча засчитывается за /DumpCfg.
    """
    low = name.lower()
    for k in keys:
        if k.lower() == low:
            return k
    for k, info in keys.items():
        if len(k) <= 2 or not low.startswith(k.lower()):
            continue
        if (info.get("arg") or "").startswith("<"):
            return k
    return None
```

- [ ] **Шаг 1: Написать скрипт доказательства**

```powershell
# Доказывает каждое блокирующее правило проверяльщика запуском на живой платформе.
# Правило имеет право блокировать, только если платформа не делает заявленного.
param(
  [string]$Exe = "C:\Program Files\1cv8\8.3.27.2325\bin\1cv8.exe",
  [string]$Base = "D:\1C\base\trade",
  [string]$Work = "$env:TEMP\1c-proof"
)
New-Item -ItemType Directory -Force $Work | Out-Null

function Run1C($name, $keys) {
  $log = Join-Path $Work "$name.log"; $rc = Join-Path $Work "$name.rc"
  $cf  = Join-Path $Work "$name.cf"
  Remove-Item $log,$rc,$cf -ErrorAction SilentlyContinue
  $a = @('DESIGNER','/F',$Base) + $keys + @($cf,'/DisableStartupDialogs','/Out',$log,'/DumpResult',$rc)
  $p = Start-Process -FilePath $Exe -ArgumentList $a -Wait -PassThru -NoNewWindow
  [pscustomobject]@{
    Имя        = $name
    КодВыхода  = $p.ExitCode
    DumpResult = if (Test-Path $rc) { (Get-Content $rc -Raw).Trim() } else { 'нет' }
    ФайлСоздан = Test-Path $cf
    Журнал     = if (Test-Path $log) { ((Get-Content $log -Encoding Default -Raw) -replace "`r?`n",' ').Trim() } else { 'нет' }
  }
}

$r = @(
  Run1C 'канон'      @('/DumpCfg')
  Run1C 'строчными'  @('/dumpcfg')
  Run1C 'выдуманный' @('/DumpCfgToFile')
)
$r | Format-Table -AutoSize
$r | ConvertTo-Json -Depth 3 | Set-Content (Join-Path $Work 'proof.json') -Encoding utf8
```

```markdown
## Что выяснить до первой правки

Состав подготовки не задан списком — он выводится из задачи. По каждому значению,
от которого зависит работа, два вопроса:

**Развилка?** Работа пойдёт по-разному в зависимости от значения — или одинаково?

**Своя починка?** Если значение окажется неверным, поправимо ли это тем же способом,
которым делалось, — или задеты накопленные данные, чужая работа, состояние поддержки,
отданное наружу; или исправлять придётся переписыванием целиком, а не правкой?

Есть развилка и нет своей починки — **спроси**, и спроси всё недостающее разом.
В остальном возьми разумное значение, **назови его вслух** и работай: названное
вслух человек поправит одним словом, а вопрос стоит ему хода.

Одно и то же значение бывает и предпосылкой, и пустяком — смотря по обстоятельствам:

- резервная копия перед загрузкой в **рабочую** базу — предпосылка: без неё
  испорченные данные не вернуть;
- та же копия перед загрузкой в **одноразовую** базу вопроса не рождает вовсе:
  чинится пересозданием.

Отсюда правило: спрашивают не про копию, а про то, рабочая база или одноразовая.
Ответ на второй вопрос отвечает и на первый.

Перечень открыт с обоих концов. Значение, на которое указал признак и которого
нет в примерах, — тоже предпосылка. Пример, к задаче не относящийся, не применяется.

**Решения, которые агент не принимает никогда,** сколько бы ни было контекста:
снятие конфигурации с поддержки и всё, что теряет чужую несохранённую работу.
Это решения владельца системы. Здесь не «спроси, если неясно», а «спроси всегда».
```

Создать `tools/check-sources.py`:

```python
"""Проверка прослеживаемости утверждений о необратимости.

Раздел «Что здесь необратимо» в любом навыке обязан ссылаться на источник:
стандарт, главу руководства либо пометку «проверено запуском». Проверяется
наличие ссылки, а не её смысл — смысл проверяет человек.

    python tools/check-sources.py
"""
import re
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
SECTION = re.compile(r"^##+\s*Что здесь необратимо\s*$", re.M)
NEXT_SECTION = re.compile(r"^##+\s", re.M)
SOURCE = re.compile(r"стандарт|глав[аеы]|приложени|руководств|проверено запуском", re.I)


def check_file(path):
    """Возвращает список абзацев без источника."""
    text = Path(path).read_text(encoding="utf-8")
    m = SECTION.search(text)
    if not m:
        return []
    rest = text[m.end():]
    nxt = NEXT_SECTION.search(rest)
    body = rest[: nxt.start()] if nxt else rest
    bad = []
    for para in [p.strip() for p in body.split("\n\n") if p.strip()]:
        if len(para) < 40:
            continue
        if not SOURCE.search(para):
            bad.append(para.replace("\n", " ")[:90])
    return bad


def main():
    total = 0
    for md in sorted((ROOT / "skills").rglob("*.md")):
        bad = check_file(md)
        if bad:
            print("[!] %s" % md.relative_to(ROOT))
            for b in bad:
                print("      без источника: %s…" % b)
            total += len(bad)
    print()
    print("утверждений без источника: %d" % total)
    return 1 if total else 0


if __name__ == "__main__":
    sys.exit(main())
```
