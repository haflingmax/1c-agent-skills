# План реализации: доработка ядра по находкам ревью

> **Исполнителю:** ОБЯЗАТЕЛЬНЫЙ ПОДНАВЫК — `superpowers:subagent-driven-development`
> либо `superpowers:executing-plans`. Шаги помечены чекбоксами `- [ ]` / `- [x]`.

**Цель:** закрыть 14 выстоявших находок ревью и 30 мелких так, чтобы чинилась причина,
а не следствие, и чтобы ни одна из 43 сильных сторон не пропала по дороге.

**Подход:** пять задач по классам дефекта, а не четырнадцать по находкам. Каждая находка
воспроизводится **до** правки; регресс из сильных сторон заводится в первой задаче
и проходит после каждой следующей.

**Спека:** [docs/specs/2026-08-23-core-remediation-design.md](../specs/2026-08-23-core-remediation-design.md)

**Находки:** [docs/reviews/2026-08-23-core-review.md](../reviews/2026-08-23-core-review.md) —
там точные формулировки Н-01…Н-14 и М-01…М-30. **Это источник требований по каждой правке:**
план задаёт порядок и способ, документ находок — что именно исправить.

**Общий план:** [docs/plan.md](../plan.md). План подчинён ему, относится к этапу ЯДРО-6.

## Global Constraints

- **Находка закрывается только парой «до» и «после».** Сначала воспроизведение —
  команда, прогон, вывод. Не воспроизвелась — не чинить, а записать, почему.
- **Мелкие М-хх подтверждаются перед правкой каждая отдельно.** Они не проходили
  состязательной проверки, часть наверняка ложные.
- **Регресс проходит целиком после каждой задачи.** Заводится в задаче 1.
- Проверки: `python tools/check-skills.py` → 0, `python tools/check-sources.py` → 0,
  `python -m pytest tests/ -q` → все зелёные.
- Кириллица: `PYTHONIOENCODING=utf-8` при запуске Python.
- Платформа для прогонов: `C:/Program Files/1cv8/8.3.27.2325/bin/1cv8.exe`,
  база `D:/1C/base/trade` — файловая, одноразовая, портить разрешено.
- `1cv8.exe` запускать только через `Start-Process -Wait`: он оконное приложение
  и без ожидания возвращает управление немедленно, ничего не создав.
- Успех операции 1С определяется по результату, а не по коду возврата и не по `/Out`.
- Скрипт блокирует только противоречащее документированному составу приложения 7;
  зависящее от замысла — предупреждение с кодом 0. **Новая блокировка законного — Critical.**
- Выгрузка ИТС в `_its/` под gitignore. Инструменты, читающие её, обязаны работать
  и без неё — либо честно отказываться с понятным сообщением.
- Прогоны Kilo и Claude Code — только там, где задача их прямо требует: они минутами.

import json

    text = path.read_text(encoding="utf-8")

    assert m, "нет фронтматтера в %s" % path
    return m.group(1)


def test_frontmatter_is_valid_yaml():
    """Н-01: фронтматтер обязан разбираться настоящим YAML, не регуляркой."""
