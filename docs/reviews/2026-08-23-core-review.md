**Предлагаемая починка.** Завести каталог правил `rules.json`: идентификатор (`1C-CLI-004 неизвестный ключ`, `1C-PLAN-002 снятие с поддержки`), уровень по умолчанию, ссылка на источник, ссылка на доказательство. check-1c-cli.py печатает идентификатор перед текстом. Это предпосылка для трёх следующих находок — без него ни подавления, ни настройки уровней, ни замера ложных срабатываний по правилам не сделать.

**Оговорка проверяющего об уровне.** Понизить Important → Minor. Ничего не ломается: сегодня это ~10 диагностик одного скрипта на 261 строку и 4 связанных с текстом утверждения из 11 (остальные 7 уже цепляются за устойчивые имена ключей и опций — `/DumpCfgToFile`, `/UsePrivilegedMode`, `-Format`).
